# 更新记录

## v2.3.0（2026-10-22）

- 采集编号不再每条自动 +1：同一采集点/同一组的所有标本共用当前编号（如都记 `HBUARA#2026-799`）。
- 换采集点/换组时手动改“本组编号”或设置里的“下一个编号”；无重复编号提示。
- 移除采集页结束按钮；统一到“统计”页“结束本次采集”。
- 采集中大圆只显示“+”，不再显示“+ 记录一条”。

## v2.2.0（2026-10-22）

### 采集流程
- 大圆未开始时为“开始一次采集”；采集中变为“＋ 记录一条”，原独立“＋ 记录一条”按钮取消。
- 结束按钮改为计时旁的小按钮“结束”。
- 结束时可填写“采集小结”（可选），写进日报；不填也可直接结束。

### 计数
- 数量改为“成年雌 / 成年雄 / 亚成体 / 幼体 / 未分”五项，总数自动求和。
- 旧记录的“性别/虫态 + 数量”自动迁移到对应计数。
- CSV 增加五项计数列；日报数量列带性别/虫态摘要。

### 名录与选项
- “类群”筛选改为“目”：蜘蛛目 / 盲蛛目（后续可加伪蝎目、裂盾目）。
- 生境、采集方法使用扩展后的默认清单，并可在设置页按行编辑、保存、恢复默认。
- 名录 CSV 第一列由“类群”改为“目”，导入仍兼容旧“类群”/“蜘蛛”等写法。

### 维护
- 新增 `MAINTENANCE.md`：文件结构、数据格式、常见修改位置、换人/换 AI 的交接提示。
- 版本号 2.2.0；Service Worker 缓存同步升级。

## v2.1.0（2026-10-22）

### 采集编号
- 改为“一组连续编号”：前缀 + 年份 + 数字，如 `HBUARA#2026-799`。
- 采集页新增“本组编号”，可随时修改本组起始号；设置页也可改前缀/年份/下一个号。
- 每保存一条自动 +1；单条编号仍可在记录表单里手动改。

### 语音
- 取消后台常驻/全程聆听；中央按钮只负责“开始/结束一次采集”。
- 输入框旁新增“语音”按钮，单次说一句，识别后按文字指令处理。

### PDF
- 新增“下载 PDF 文件”（图片版）：任何浏览器都能直接保存，解决夸克/微信无法“打印为 PDF”的问题。
- “打印 / 另存”仍保留，电脑上可生成矢量 PDF。

### 定位
- 定位失败时显示“不可用/超时”等错误类型。
- 说明 Edge 安卓在中国大陆可能因缺少定位服务无法定位，建议 Chrome/夸克或手填坐标。

## v2.0.0（2026-10-22）

### 主记录流程
- 改为“科 → 属 → 种”逐级选择：点“＋ 记录一条”先出科列表，再进入属、种。
- 每一级都有 `sp.` 按钮：科级可直接记“园蛛科 sp.”，属级可记“Argiope sp.”，不必选到种。
- 顶部搜索框支持科/属/种/拉丁名，可直接跳到种（跳级搜索）。
- 记录表单支持“更换分类”。

### 名录
- 内置《中国蜘蛛名录（陆千乐整理，2023-01-12）》：72 科、892 属、5875 种。
- 内置 `盲蛛.docx`：43 科、166 属、1521 种；36 个科暂无种级记录，保留科/属 `sp.` 入口。
- 新增“类群”字段（蜘蛛/盲蛛），科列表可按类群筛选。
- 设置页支持 **选择 CSV 文件** 导入（替换/合并），同时保留粘贴导入。
- 名录数据独立到 `taxonomy-data.js`；CSV 备份为 `分类名录_v2.csv`。

### 记录与编号
- 记录编号在表单中 **可手动修改**；重复编号会提示确认。
- 记录新增“类群”字段；CSV 增加“类群”列。
- 统计里的 `sp.` 记录显示为“园蛛科 sp.”或“园蛛科 / Argiope sp.”，不再重复。

### 语音
- 语音降为辅助；仍支持“横纹金蛛三头”直接记一条，以及开始/结束/统计/撤销。
- 主流程不再依赖语音，没有麦克风或无网络也能完整记录。

### 定位
- 打开“＋ 记录一条”时自动请求定位，不必先开始采集。
- 仍建议在 HTTPS 下使用；`file://` 不支持定位。

### 维护
- 版本号升到 2.0.0；v1 源码备份在 `versions/v1/`。
- 名录、界面、逻辑分离；不压缩、不打包，方便后续修改。
- `README.md` 更新为 v2 流程；新增本更新记录。
