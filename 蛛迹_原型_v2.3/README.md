# 蛛迹 · 野外蛛形动物采集记录（v2.3）

手机优先、离线可用的网页应用（PWA），用于蛛形动物采集记录。

v2.3 的核心变化：**大圆开始一次采集，采集中变成“+”**；主记录用“目 → 科 → 属 → 种”逐级选择，任意一级可点 `sp.`；记录按“成年雌/雄、亚成体、幼体、未分”计数；同一采集点共用一个编号；语音只保留单次辅助。

---

## 一、怎么用（主流程）

1. **设置**：填采集人、地点；需要时手填温湿度/坐标。
2. **大圆“开始一次采集”**：点击后进入本次采集；大圆变成 **“+”**，点它开始逐级选择。
   - 先选**目**（蜘蛛目/盲蛛目），再选**科** → **属** → **种**；
   - 任意一级点右侧 **`sp.`**，直接记到这一级（如“园蛛科 sp.”、“Argiope sp.”）；
   - 顶部搜索框输入科/属/种/拉丁名，可**直接跳到种**，不用逐级点。
3. **记录表单**：成年雌、成年雄、亚成体、幼体、未分五个数量（总数自动求和），加生境、方法、备注、照片；**记录编号自动生成，也可以手动改**。
4. **结束**：到“统计”页点“结束本次采集” → 可写“采集小结（可选）”→ 生成日报；不写也可直接结束。采集页不再放结束按钮。
5. **统计 → 下载 PDF 文件 / 打印**：图片版 PDF 任何浏览器可保存，打印版为矢量。

### 采集编号

“设置 → 采集编号”或采集页的“本组编号”里设置：

- 前缀：`HBUARA#`
- 年份：`2026`
- 下一个编号：`799`

同一个采集点/同一组的所有标本共用当前编号，例如都记 `HBUARA#2026-799`；**不会每条自动 +1**。
换采集点/换组时，点“本组编号 → 修改”或到设置页把“下一个编号”改成 `800`，之后的记录都用新号。
单条编号在记录表单里也能单独改。

### 生境 / 采集方法

设置页可直接编辑两份清单（每行一个），保存后立即出现在采集页；默认清单已覆盖林地、倒木、石下、洞穴等生境，以及手捡、扫网、筛落叶、Berlese 漏斗、马氏网、灯诱等采集方法。

### 语音（辅助）

不再后台常驻。点输入框旁的“**语音**”说一句，识别后按文字指令处理；说 **“横纹金蛛三头”** 仍可直接记一条。听不清时用逐级选择，不会写错。

## 二、内置名录（v2）

| 蜘蛛目 | 72 | 892 | 5875 |
| 盲蛛目 | 43 | 166 | 1521 |

- 蜘蛛数据来自《中国蜘蛛名录（陆千乐整理，2023-01-12）》。
- 盲蛛数据来自 `盲蛛.docx`；其中 **7 个科有 species 级记录**，其余 36 个科目前只有科名/属名，已保留“科 sp.”“属 sp.”入口，等后续补充。
- **蜘蛛的科中文名只收录了常用科**；未收录的科在界面上显示拉丁名（如 `Caponiidae`），不影响按拉丁名检索和记录。
- 蜘蛛的属中文名原始表里没有，属级显示拉丁名；种级有中文名。

## 三、换成自己的名录

“设置 → 分类名录”支持两种方式：

1. **粘贴 CSV**；
2. **选择 CSV 文件**（替换或合并）。

列顺序（8 列）：

```
目,科中文,科拉丁,属中文,属拉丁,种中文,种拉丁,别名
```

- 别名用分号 `;` 分隔，可留空
- 只到属：种中文、种拉丁留空
- 只到科：属、种都留空
- 旧版 7 列（没有“目”）仍可导入，默认归为“蜘蛛目”

“替换”会整体替换；“合并”按“目+科+属+种拉丁”去重合并。

## 五、定位说明

- 浏览器只在 **HTTPS 或 `http://localhost`** 下允许定位；双击 `index.html`（`file://`）会失败。
- 打开记录表单或点“开始一次采集”时会自动请求定位。
- **Edge 安卓在中国大陆常因缺少 Google 定位服务无法定位**（权限全开也没用）；可改用 Chrome/夸克定位，再用“下载 PDF 文件”导出。
- 手机需允许 Chrome 使用定位；电脑 Edge 还需要 Windows 设置里打开“定位”。

## 六、已知边界

- **语音识别**：浏览器 Web Speech API，安卓 Chrome 需联网，境内可能因服务不可用而失败；已取消后台常驻，只保留“说一句”辅助，文字/逐级选择始终可用。
- **海拔**：优先 DEM（约 90 m 分辨率），其次 GPS；误差约 ±10–30 m。
- **天气**：Open-Meteo 在线获取；无网络时手填。
- **PDF**：日报里有两个出口——“**下载 PDF 文件**”是图片版，任何浏览器（含夸克/微信）都能保存；“**打印 / 另存**”生成矢量版，适合电脑。
- **照片**：存在浏览器 IndexedDB，不进入 JSON 备份，也不进入 PDF。
- **数据**：保存在“浏览器 + 网址”里；换网址/清缓存会丢，务必每天导出 JSON 备份。
- **坐标系**：WGS84；与国内地图底图叠加时注意 GCJ-02 偏移。
